# Mehdi Mejbar — AI & Data Engineering Portfolio

Personal portfolio for PFE opportunities starting February 2027.

## Website

Custom domain: https://mehdimejbar.com

## Contents

- `index.html`: portfolio content and original dark AI theme.
- `professional.css`: responsive styling for project and contact sections.
- `Mehdi-Mejbar-CV.pdf`: downloadable CV.
- `.nojekyll`: serves the static files directly on GitHub Pages.
- `CNAME`: custom domain used by GitHub Pages.

Open `index.html` in a browser for local preview. No build step is required.

## Deployment

GitHub Pages should publish the `main` branch from `/ (root)`. Domain DNS and HTTPS are configured in GitHub Pages settings and the domain provider.
